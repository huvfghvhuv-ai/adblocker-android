# 广告弹窗拦截器 (Ad Blocker for Android)

这是一个针对Android系统的广告弹窗拦截应用，利用无障碍服务监控窗口变化并自动关闭检测到的广告弹窗。

## 功能特点

- **基础拦截**：通过无障碍服务实时监控窗口状态变化，根据预定义规则检测并关闭广告弹窗
- **规则管理**：用户可以添加、编辑和删除自定义规则来定制拦截行为
- **日志记录**：记录被拦截的广告弹窗信息，便于查看和调试
- **简单易用**：一键启用/禁用无障碍服务，提供清晰的状态提示

## 项目结构

- `MainActivity`: 主界面，提供无障碍服务开关和功能入口
- `PopupDetectionAccessibilityService`: 无障碍服务实现，负责监控窗口变化和执行拦截逻辑
- `RuleManagementActivity`: 规则管理界面，用于添加、编辑和删除广告检测规则
- `LogsActivity`: 日志查看界面，展示被拦截的广告记录
- `AdRule`: 广告检测规则的数据模型
- `RuleManager`: 规则的加载、保存和默认规则管理
- `Logger`: 简单的日志记录工具，写入文件和Logcat

## 如何使用

1. 安装应用后打开
2. 点击“启用广告拦截”开关，这将引导您到系统无障碍服务设置页面
3. 在无障碍服务设置中找到“广告拦截器”服务并启用它
4. 返回应用，您应该会看到状态变为“无障碍服务已启用 - 广告拦截器正在运行”
5. 现在，当检测到匹配规则的广告弹窗时，服务将自动尝试关闭它（通过返回手势）
6. 您可以在“管理规则”界面添加自定义规则来调整拦截行为
7. 在“查看日志”界面查看被拦截的广告记录

## 注意事项

- 无障碍服务需要用户手动开启权限，这是Android系统的安全机制
- 该服务通过模拟返回手势来关闭弹窗，对某些特殊弹窗可能无效
- 建议先从默认规则开始使用，然后根据个人使用情况添加自定义规则
- 过于激进的规则可能导致误拦截，请谨慎添加规则

## 技术实现

- 使用Android无障碍服务（AccessibilityService）监听`TYPE_WINDOW_STATE_CHANGED`事件
- 通过分析窗口的包名和文本内容匹配用户定义的规则
- 匹配成功后执行`GLOBAL_ACTION_BACK`全局动作尝试关闭弹窗
- 规则采用JSON格式存储在应用的内部存储中
- 日志同样存储在内部存储中，便于查看
